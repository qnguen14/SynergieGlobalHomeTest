## Project features:
- Shows today's lesons, no scrolling.
- Whenever families send a cancellation request, the receptionist can see and update the lesson's status so the tutor is able to see their booked lesson's current status.
- Two students can book one session per tutor *if currently in exam seasons*.
- Show notes on each current status of the tutoring session.

## Tech stack: 
### Back-end: ASP.NET 8.0 C# 
### Front-end: React.JS
### Database: PostgreSQL (Neon)
